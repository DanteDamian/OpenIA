# Descripción

El repositorio vacío ahora contiene una aplicación Next.js con TypeScript y Tailwind, navegación responsive y siete módulos administrativos. El dashboard usa estados vacíos para evitar presentar información financiera ficticia.

Incluye adaptadores Supabase mediante variables públicas, sin conexiones activas, reglas de desarrollo y seguridad en AGENTS.md, ejemplo de entorno sin credenciales y CI con lint, tipos, pruebas y build. No implementa todavía CRUD, login, OpenAI ni Alegra.

Validación: lint, tipos y build aprobados; 8 pruebas aprobadas; 9 rutas verificadas por HTTP y una ruta desconocida con 404. Dependencias de producción: npm audit reporta 0 vulnerabilidades. Detalles y límites en docs/VALIDATION.md.

No se ha desplegado a producción. Antes de manejar datos reales deben implementarse autenticación, autorización y RLS por organización.
